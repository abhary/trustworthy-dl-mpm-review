# User guide

## 1. What the code does

`src/generate_figures_and_tables.py` reads the derived CSV files in `data/` and regenerates the review's programmatic figures, manuscript tables and Supplementary Data S1–S6. It does not train a neural network and does not require a GPU.

`tests/quick_test.py` is a short integrity/reproducibility check. It recomputes the key manuscript counts from the quality matrices and compares them with the expected summary supplied in `tests/expected_quick_test_summary.csv`.

## 2. Hardware and software

- Hardware: standard desktop or laptop computer; CPU execution is sufficient.
- Operating system: Windows, macOS or Linux with Python 3.11.
- Python: 3.11 recommended.
- Main dependencies: pandas, NumPy, Matplotlib and Pillow.
- No proprietary software is required.

## 3. Inputs

The main inputs are CSV files in `data/`:

- `standardized_integrated_evidence_matrix.csv` — integrated 32-study evidence matrix.
- `adjudicated_consensus_quality.csv` — 25-study secure-core reliability scores.
- `sensitivity_consensus_scores.csv` — seven independently adjudicated sensitivity records.
- `domain_profile.csv` — twelve-domain reliability profile.
- `prisma_operational_accounting.csv` — review-flow accounting.
- `reliability_taxonomy.csv` — model/reliability taxonomy counts.
- `sensitivity_analysis_summary.csv` — predefined sensitivity scenarios.
- `pilot_competing_reviews.csv` — competing/adjacent review landscape used in the novelty synthesis.
- `search_query_register.csv` — search-query register for Supplementary Data S3.
- `full_text_exclusion_register.csv` — full-text exclusion register for Supplementary Data S4.
- `reconciled_reference_register.csv` — reconciled bibliographic register for Supplementary Data S6.

## 4. Outputs

A successful full run creates:

- `outputs/figures/` — Figures 1–8, Supplementary Figures S1–S4 and the graphical abstract produced programmatically.
- `outputs/tables/` — manuscript Tables 1–8 plus the quick-test summary.
- `outputs/supplementary/` — Supplementary Data S1–S6.
- `outputs/visual_assets_manifest.json` — concise inventory of generated visual assets.

Some manuscript figures/tables assembled outside the programmatic workflow are not regenerated by this script; the repository is intended to reproduce the quantitative review synthesis and programmatic assets represented by the included pipeline.

## 5. Run the quick test

From the repository root:

```bash
python tests/quick_test.py
```

Expected behaviour: the script exits with status 0, prints a pass message, and writes `outputs/tables/quick_test_summary.csv`. If any key count differs from the expected values, the test raises an `AssertionError` and displays the mismatch.

## 6. Run the full workflow

```bash
python src/generate_figures_and_tables.py
```

Expected behaviour: the script exits with status 0 and prints the path of the generated visual assets. Existing files with the same output names are overwritten.

## 7. Reproducibility notes

The workflow is deterministic for the included tables and plotting operations; no stochastic model training occurs. All source data needed by the public workflow are supplied as individual files. The expected quick-test summary is committed so that a reviewer can verify the headline counts immediately; programmatic figures and tables are regenerated locally by the full workflow.

## 8. Troubleshooting

- `ModuleNotFoundError`: install dependencies with `pip install -r requirements.txt` or create the conda environment.
- Missing CSV error: run commands from the repository root and confirm that `data/` is intact.
- Font differences in plots: Matplotlib uses DejaVu Sans; minor renderer differences across operating systems can alter pixel-level output while leaving the data and labels unchanged.
